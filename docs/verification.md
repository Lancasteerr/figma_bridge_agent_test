## 页面和交互约定

- 仅呈现主页；Figma 右侧的组件样例用于参考按钮状态，不展示在网页中。
- 以 1440 × 1668 设计尺寸实现。内容区域宽 1227px，三栏宽 225 / 681 / 287px，间隔 17px。
- 顶栏在 y=34、两侧栏在 y=167 驻留，中间内容随文档纵向滚动。使用 CSS sticky 保留横向文档对齐，不增加嵌套滚动区。
- 窄屏保留桌面布局，可横向滚动；宽屏内容居中，保留原稿左右留白相差 1px 的偏移。背景独立固定，以 cover 覆盖可用窗口区域。
- 横幅为单张静态图片。分类只切换高亮，不筛选或重排文章。
- 点赞和关注可反复切换。第一篇初始未点赞、未关注，第二篇初始已点赞、已关注。第二篇显示 `12.8k`，本地演示基数为 12800。
- 搜索允许输入，回车或点击搜索按钮显示提示。文章标题、封面、评论、发布、管理作品和头像入口仅显示对应提示，无详情页或数据请求。
- 提示约 2.5 秒后消失，新提示覆盖旧提示，不挤压布局、不抢夺焦点。
- 状态只保存于 React 内存，刷新恢复设计初始态。原生按钮支持 Enter / Space，分类、关注、点赞通过 `aria-pressed` 暴露选中状态。

## 模块

- `src/components`：顶栏、分类、发布卡片、文章、按钮、图标、标题与提示条。
- `src/data/community.ts`：插件事实中的文章文案和初始状态。
- `src/hooks/useToast.ts`：提示计时和卸载清理。
- `src/styles.css`：插件尺寸、色值、字体、裁切和用户确认的滚动规则。
- `public/assets`：通过插件导出的五张原始图片和九个 SVG 图标。
- `public/fonts`：本机 Noto Sans SC 可变字体的页面字符子集，附 SIL OFL 授权文本。编辑静态中文文案后，应同步扩充字体子集；任意输入字符允许由系统字体补足。

## 已知差异

选中项左侧蓝条存在约 1px 外偏。插件事实中，节点 `84:682` 的 `renderOnPage` 显示可见蓝条应从选中项左边缘向内占 2px；当前 `src/styles.css` 的 `.category-button[aria-pressed='true']::before` 使用 `left: -1px; width: 2px`，使其部分超出选中项边界。

该装饰伪元素未包含在此前主要容器几何检查中。本次保留真实实现并记录差异，没有修改前端代码；后续修复应将其左偏移改为 `0` 并针对该可见边界核对。
